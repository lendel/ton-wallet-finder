Why this tool

Built for keys you can trust

It creates real private keys, so it is designed to be small, auditable and boring in the best way.

Zero dependencies

Only Node.js built-ins. No network calls — your keys never leave the computer.

Encrypted results

Asks for a password before the search and saves the mnemonic to an encrypted file.

Every CPU core

Parallel search on worker threads with live progress, speed and expected time.

Verifiable releases

Published from CI with npm provenance. Crypto pinned to @ton reference vectors.

How it works

Three commands, one wallet

Requires Node.js 22 or newer. Nothing to install globally.

1

Pick an ending

Latin letters, digits, “-” and “_”. Case-sensitive: abc ≠ ABC.

npx tonwf cafe
2

Let it search

Set a password, watch the progress. Ctrl+C stops the search cleanly.

-w v5r1  -j auto
3

Import and verify

Decrypt the file, import the 24 words into your wallet and check the address.

npx tonwf --decrypt ton_wallet_results.enc.json
Time estimate

How long will it take?

Wallet versions

Match the wallet you use

The same 24 words give a different address for every contract version. Search with the one your wallet app uses.

FlagContractWhere
-w v5r1WalletV5R1 (W5) CLI defaultTonkeeper, Telegram Wallet, MyTonWallet
-w v4r2WalletV4R2Widely supported; library default
-w v3r2WalletV3R2Legacy, still importable in most wallets

⚠ Treat the output like cash

  • Run it on a machine you trust — not in CI or a shared environment.
  • Keep the encrypted file; avoid printing the mnemonic where output is logged.
  • Before sending funds, import the words and check that the wallet shows exactly the found address.
